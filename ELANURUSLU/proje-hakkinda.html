🎯 Proje Amacı

Bu proje, İstanbul'un üç farklı semtini (Üsküdar, Bahçeşehir ve Çekmeköy) fotoğraflar aracılığıyla tanıtmayı ve web tasarımı dersi kapsamında HTML5 ve CSS3 teknolojilerini kullanarak kapsamlı bir web sitesi geliştirmeyi amaçlamaktadır.

Hedef Kitle:

  • Işık Üniversitesi öğrencileri
  • Fotoğraf meraklıları
  • İstanbul'u keşfetmek isteyenler
  • Web tasarımı öğrencileri

Kullanılan Teknolojiler

HTML5

  • Semantik HTML yapısı
  • Tablolar (timetable sayfası için)
  • Formlar (iletişim sayfası)
  • İframe (Google Maps entegrasyonu)
  • Çoklu medya desteği (resimler)

CSS3

  • CSS Variables (özelleştirilebilir renkler)
  • Flexbox Layout
  • CSS Grid Layout
  • CSS Transitions ve Animations
  • Responsive Design (Media Queries)
  • CSS-only Navigation ve Dropdown Menüler
  • Pseudo-elements ve Pseudo-classes

Özel Özellikler

  • JavaScript kullanılmadan tamamen CSS ile interaktif menü
  • Modüler CSS yapısı (3 ayrı CSS dosyası)
  • Dark theme tasarım
  • Mobil öncelikli responsive tasarım
  • Erişilebilirlik standartlarına uygunluk

🔧 Teknik Özellikler

HTML5 Semantik Etiketler

  • <header> - Sayfa başlıkları
  • <nav> - Navigasyon menüsü
  • <main> - Ana içerik
  • <section> - İçerik bölümleri
  • <footer> - Sayfa alt bilgisi
  • <article> - Bağımsız içerik

CSS3 Advanced Teknikleri

  • CSS Variables: Kolay renk yönetimi
  • Flexbox: Esnek layout sistemi
  • Grid: 2D layout sistemi
  • Transitions: Smooth animasyonlar
  • Transform: Hover efektleri
  • Media Queries: Responsive tasarım
  • Pseudo-elements: ::before, ::after
  • Pseudo-classes: :hover, :focus, :checked

CSS-only Interaktif Özellikler

  • Checkbox ile hamburger menü
  • :hover ile dropdown menü
  • Transform ile hover efektleri
  • Transition ile smooth animasyonlar
